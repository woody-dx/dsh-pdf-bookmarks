# Liberation 字体源码

PDF.js 6.3.289 使用 Liberation Sans 1.07.4，依据 Mozilla 对应版本的说明：
https://github.com/mozilla/pdf.js/blob/v6.3.289/external/standard_fonts/README.md

本目录随插件安装包提供未改动的完整上游源码归档 `liberation-fonts-1.07.4.tar.gz`，包含 16 个 SFD 字体源文件、Makefile、FontForge 构建脚本、README 与原始许可证。

- 原始分发者归档：https://www.sourceware.org/pub/cygwin/noarch/release/liberation-fonts/liberation-fonts-1.07.4-1-src.tar.xz
- Cygwin 源码包 SHA-256：96938a0437a73e215898e0475a0c00ea9e251547f7e69cd76012163bb16c7375
- 从其中原样取得的上游源码归档 SHA-256：ad98b7498dc2992f7f0868f79b65ce4a720a3acdb63ab3f1f1cb6881117a5406
- 字体许可：GPLv2 与 Liberation 字体例外，全文见 License.txt 和 COPYING。

修改或重建字体可解压源码归档，按归档内 README/Makefile 使用 FontForge 和 make。插件安装不执行这些脚本。发布者没有修改字体。
